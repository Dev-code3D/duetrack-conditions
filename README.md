# DueTrack — Pages juridiques

Pages de confidentialité et conditions d'utilisation pour **DueTrack**, un outil simple et privé de suivi de prêts, dettes et transactions.

## 📋 Contenu

Ce dépôt contient les pages publiques statiques de présentation et juridiques de DueTrack :

- **`index.html`** — Page d'accueil avec présentation, fonctionnalités et FAQ
- **`confidentialite.html`** — Politique de confidentialité
- **`conditions.html`** — Conditions d'utilisation
- **`styles.css`** — Feuille de styles partagée
- **`script.js`** — Comportements interactifs (menu, thème, etc.)

## 🛡️ Sécurité et données

Cette page est **entièrement statique** et hébergée via GitHub Pages. Aucune donnée utilisateur n'est collectée ni transmise à partir de ces fichiers. Ne commitez jamais :

- Clés API, tokens ou secrets d'accès
- Fichiers `.env` ou de configuration sensible
- Exports personnels ou archives de données
- Logs ou métadonnées confidentielles
