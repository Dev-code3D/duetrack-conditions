# Site public DueTrack

Ce dossier contient le site statique de présentation et les pages
juridiques de DueTrack. Il peut être copié dans le dépôt GitHub Pages
`Dev-code3D/DueTrack-Web`.

## Publication

1. Copier `website/` dans le dépôt Pages.
2. Copier `DueTrack_Icon.png` dans `assets/DueTrack_Icon.png`.
3. Activer GitHub Pages sur la branche publiée.
4. Vérifier les liens, l’identité légale, le contact et les dates.
5. Faire relire les pages Confidentialité et Conditions par un professionnel
   avant une publication commerciale.

Le site ne contient aucune clé ni donnée utilisateur. Ne jamais ajouter un
fichier `.env`, token, archive de signature, export ou clé `service_role`.

Les pages juridiques sont un modèle informatif à adapter au pays de l’éditeur,
aux fournisseurs effectivement activés et aux fonctions réellement publiées.
